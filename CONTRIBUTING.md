# Contributing

This repository is a **one-way sanitized mirror** of a private harness. It is regenerated by an export pipeline on each release — nothing here is edited in place, and its git history starts fresh by design.

What that means for contributions:

- **Issues and PRs are welcome.** They are reviewed, applied to the private source of truth (possibly adapted), and appear here in the next sync commit. Your PR itself will not be merged directly — expect a "landed upstream, closing" resolution with credit in the sync notes.
- **Small, rationale-carrying changes work best.** This harness records *why* alongside *what* (see the design principles in the README) — a PR that explains the failure mode it prevents is far easier to adopt than a style preference.
- **Don't send secrets, personal data, or company-specific content.** The export gate would block the next sync if it slipped in.

If you build something on top of this, an issue linking your derivative is appreciated — derivatives are part of the feedback loop this mirror exists for.
