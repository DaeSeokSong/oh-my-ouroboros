# /dumbify — 눈높이 재작성 (전문용어 → 중학생 독해 수준)

> **출처 각인 (MIT)**: artemnovitckii/content-skills의 dumbify를 한글 연구 보고 맥락으로 적응 (2026-07-15 도입, 원문은 영어 SNS 콘텐츠 기준 — 8th-grade 지표를 "한국 중학생 독해 수준"으로 치환). 원 저작 MIT 라이선스, 파생 허용.
> **하네스 정합**: CLAUDE.md 보고 스타일의 2) 쉬운 설명·3) 중학생 예시가 요구하는 "무엇"에 대한 **"어떻게"(방법론)** 를 제공한다. `rules-lazy/answer-detail.md`와 상호 참조.

## 사용 주체 · 시점

- **main**: 보고 스타일 2) 쉬운 설명·3) 예시 단계 생성 시 기법으로 상시 참조 (스킬 호출 아닌 내부 활용 — 자동 제안 불필요)
- **researcher / neuro-explain 스킬**: 학술 내용의 대중적 설명 구간
- 명시 트리거: "쉽게 설명해줘", "무슨 말인지 모르겠어", "비전문가에게 설명한다면"

## 기법 (순서 적용)

1. **용어 치환** — 전문용어마다 "이 단어를 처음 듣는 사람에게 뭐라고 부를까?"를 자문해 일상어로 교체. 교체 불가능한 핵심 용어(논문 용어 등)는 유지하되 **첫 등장에서 한 줄 정의** 병기.
2. **문장 해체** — 한 문장 = 한 주장. 관계절 2개 이상 중첩 금지, 접속 남용 금지.
3. **능동태·구체 주어** — "~가 수행되었다" → "X가 ~했다".
4. **필러 제거** — "기본적으로", "일종의", "어떤 의미에서는" 삭제.
5. **비유 1개** — 개념당 실생활 비유 최대 1개 (보고 스타일 3) 과 연결 — '예시' 표기).

## 가드레일 (과잉교정 금지 — 원문 안전장치 계승)

- **정확도 우선**: 수치·조건·한계·불확실성 표기는 절대 단순화로 소실시키지 않는다 — 낮추는 것은 표현이지 내용이 아니다.
- **독자 무시 금지**: 유치한 어투·과도한 감탄사로 리듬을 깨지 않는다. 전문가 사용자에게는 1) 기술 설명이 본체이고 2) 쉬운 설명은 보조다.
- 코드·수식 원문은 재작성 대상이 아님 (설명 텍스트만).

## 4-Gate

외부 부작용 없는 순수 방법론 — Gate 2) 필요성(설명형 콘텐츠인가)·4) 컨텍스트만 실질 판단. 깊이 제한 N=1 준수.
