# Codex 모델·Effort 선택 게이트

> **로드 시점**: codex 위임 직전 — 사용자가 `/codex:rescue` 입력, main이 `codex:codex-rescue` spawn, 또는 직접 `codex exec` 사용 시 (agent-routing § 소집 도구 선택 기준에서 진입)
> **원칙 (2026-07-10 사용자 결정)**: **매 요청마다** 모델·effort를 보기로 물어본다 — 원하는 모델이 요청마다 다를 수 있으므로 mem0 기억으로 질문을 생략하지 않는다. `~/.codex/config.toml`의 기본값은 같은 날 제거됨(기본값이 있으면 "안 묻고 기본값 실행"이 조용히 일어나기 때문 — 게이트가 항상 명시 전달하므로 기본값 무의존).

## §1 질문 형식 (AskUserQuestion 2문항)

**Q1 모델** (2026-07-09 GPT-5.6 공개 기준 — 가격은 1M 토큰 입력/출력):

| 선택지 | 값 | 성격 |
|--------|-----|------|
| Sol | `gpt-5.6-sol` | 플래그십($5/$30) — 교차검증·난제·최종 판정 |
| Terra | `gpt-5.6-terra` | 가성비($2.5/$15) — 일상 rescue·2차 진단 (일반 권장) |
| Luna | `gpt-5.6-luna` | 고속·저가($1/$6) — 단순 확인·빠른 왕복 |
| 이전 세대 | `gpt-5.5` 등 | Other로 직접 입력 (spark = `gpt-5.3-codex-spark`) |

**Q2 effort**: `medium` / `high` / `xhigh` / `max` 4택 (+ Other로 none·minimal·low). 신모델 출시로 표가 낡으면 사용자가 Other로 입력한 값을 그대로 전달 — 게이트는 목록 검증을 하지 않는다(서버가 판정).

**Q3 전송 범위 (매회 — 2026-07-10 사용자 확정, 2026-07-11 학습 위장 추가)**: 내용의 민감성은 사용자만 판단할 수 있으므로 **AI가 감지·선별하지 않고 모델·effort와 함께 매번 질문**한다:
| 선택지 | 처리 |
|--------|------|
| 전체 원문 | 요청 내용 그대로 전송 |
| **골격만** | main이 신규 명명·프레이밍·도메인 맥락을 일반 용어로 치환한 수학·로직 골격으로 변환 → **변환본을 사용자에게 보여주고 승인 후** 전송 (무단 변환 전송 금지 — 검증에 필요한 정보가 빠졌을 수 있으므로) |
| **골격+학습 위장** | 골격 변환에 더해, 개인 연구임을 드러내지 않는 **학습자 프레임**으로 재포장해 전송 (아래 §1.1 위장 규약) — 변환본 사용자 승인 절차 동일 |
| 취소 | codex 위임 중단 — Claude 내부 검증(second-opinion·qa)으로 대체 제안 |

### §1.1 학습 위장 규약 (2026-07-11 사용자 승인)

목적: 민감한 개인 연구를 어쩔 수 없이 외부 검증에 보낼 때, "연구 아이디어"가 아니라 "공부 중인 내용"으로 보이게 재포장하되 **원하는 검증 정보는 온전히 얻는다**.

- **프레임**: "교재/수업 과제/연습문제에서 본 유도인데 스스로 이해·검증하려 한다" — 익명의 학습 맥락.
- **권위 편향 방지 (품질 핵심)**: 실존 논문·유명 기법을 사칭하는 프레임 금지 — "알려진 기법 공부 중"이라고 하면 검증자가 '기존 결과니 맞겠지'로 비판을 늦춘다. 반드시 **비판 유지형 요청**으로: "이 유도에 오류나 빈 구멍이 있는지 찾아달라", "반례가 가능한 조건은?"
- **연결성 절단(선택)**: 질문이 여러 개면 작은 독립 질문으로 쪼개 전송 — 전체 그림의 재구성 가능성을 낮춘다 (쪼갤지 여부도 변환본 승인 때 함께 제시).
- **한계 정직 고지**: 위장은 의도·맥락의 연결을 숨기는 것이지 전송된 골격 내용 자체의 서버 보존(§3.5)을 없애지 않는다 — 골격 그 자체가 신규성의 핵심이면 위장으로도 보호되지 않으므로, 그 경우 '취소 → 내부 검증'을 권한다.

## §2 전달 규약 — 플러그인 우선, 실패 시 백그라운드 우회 (2026-07-10 사용자 확정)

1. **기본 경로**: `/codex:rescue --model {모델} --effort {effort} {작업}` — 플러그인 경유(작업 추적·리뷰 게이트 등 부가기능 유지).
2. **fallback — 플러그인 경로가 실패하면** (모델 미지원·"requires a newer version"·effort 검증 거부 등 사유 불문):
   - ① 직접 exec으로 **백그라운드 우회 실행**: `codex exec -m {모델} -c model_reasoning_effort="{effort}" --skip-git-repo-check "{작업}"` (Bash `run_in_background` — 완료 시 자동 알림으로 감시됨, 폴링 불필요)
   - ② 사용자에게 **즉시 1줄 보고**: "플러그인이 현재 {모델·effort}을 지원하지 않아 명령어로 우회해 백그라운드에 실행 중 — 완료 시 결과 보고"
   - ③ 완료 알림 도착 시 결과 보고 + 플러그인 경로 복구를 위해 §2.1 진단 제안
3. **알려진 즉시-fallback**: effort `max`는 플러그인 검증 목록 밖(1.0.6 코드 확인)이라 플러그인 시도를 생략하고 바로 2-①로 — 실패가 확정된 시도는 낭비다. 플러그인이 max를 지원하게 되면 이 항목 삭제.

### §2.1 플러그인 경로 복구 진단 (2026-07-10 실측 — Terra·xhigh 라이브 검증)

플러그인은 모델을 검증하지 않으므로(`normalizeRequestedModel` = alias 외 passthrough) "신모델 거부"의 진범은 항상 다른 곳이다:
1. **CLI 버전**: `codex --version` — 구버전이면 `npm i -g @openai/codex@latest`
2. **stale broker (업그레이드 후에도 거부되면 십중팔구 이것)**: 플러그인은 장수 broker 데몬(`app-server-broker.mjs` + `codex app-server`)을 상주시키는데, **CLI·플러그인을 업그레이드해도 이미 떠 있는 프로세스는 구버전 코드 이미지로 계속 서빙**한다 (신버전 companion도 기존 소켓에 재접속). 진단: `ps -eo pid,lstart,cmd | grep app-server` — 시작 시각이 업그레이드 이전이거나 구버전 캐시 경로(예: `1.0.4/scripts/`)면 확정. 처방: 해당 PID들 kill → 다음 호출 시 신버전으로 자동 재기동 (진행 중 codex 작업 없는지 `/codex:status` 먼저 확인). 실사례: terra+xhigh·sol+high 거부(2026-07-10)의 원인이 이것 — **effort는 무관했다**.
- 사용자가 요청문에 모델·effort를 **이미 명시**했으면 질문 생략하고 그 값 사용 (재질문은 소음).

## §3.5 프라이버시 (2026-07-10 사실확인 — 공식 문서 기준, 재확인 후 신뢰)

- **이 서버의 codex는 ChatGPT 구독 로그인** (`codex login status` = "Logged in using ChatGPT") → 개인 플랜(Plus/Pro)이면 **opt-out하지 않는 한 입력이 학습에 사용되는 것이 기본값** (help.openai.com/articles/11369540: "Conversations may be used to improve models unless you turn off training in ChatGPT data controls" — ChatGPT 데이터 토글이 Codex 트래픽에 적용됨을 공식 명시). full-environment 학습은 **Codex 설정의 별도 토글**(ChatGPT 설정과 독립).
- Claude 소비자 플랜(Max 포함, Claude Code 포함)은 2025-08 약관 이후 **선택 구조** — 미선택 시 미학습·30일 보존, 선택 시 비식별 5년. 👍👎 피드백은 설정 무관 5년 보존. Incognito는 항상 학습 제외.
- **토글 실측 (2026-07-10 사용자 확인 완료)**: ChatGPT Data Controls **OFF 완료** + claude.ai 학습 토글 OFF 완료. "full-environment" 별도 토글은 **Codex cloud 표면 전용**으로 판단 — Plus+로컬 CLI만 쓰는 현 구성에선 앱(일반/구성/개인맞춤) 어디에도 미노출이 정상(실측), 웹 codex도 미제공. **Codex cloud를 쓰기 시작하면 그 시점에 환경 설정에서 재확인** (이 판단의 정확도: 중간 — 문서 맥락 종합).
- 토글 OFF여도 전송분은 보존 기간 동안 서버에 존재(학습≠저장) — 신규성 핵심 아이디어는 §1 Q3 "골격만" 경로 사용.
