> **로드 시점**: `claude-security` 플러그인 스캔 실행 직전 (라우팅 2.7 대규모 단계 진입 시)
> **원칙 (2026-07-31 사용자 결정 — codex-model-gate 패턴 이식)**: 스캔 깊이가 곧 비용(플랜 토큰 차감, 별도 요금 없음)이므로 **매 실행 전** 깊이·범위를 보기로 물어본다. 요청문에 이미 명시된 경우만 생략 (재질문은 소음).

## §1 질문 형식 (AskUserQuestion 2문항 — 고르게 하는 것이므로 결정 팝업이 우선, CLAUDE.md 원칙 7.5)

**Q1 깊이** (소모 근거: 2026-07-31 조사 — max 전체 스캔 실사용 754k+ 토큰 보고, Instant는 모델 호출 0):

| 선택지 | 성격 | 예상 소모 |
|--------|------|----------|
| Instant | 패턴 매칭만 — **effort 단계가 아닌 별도 instant check 기능** (플러그인에 미노출이면 빌트인 `/security-review`로 대체). ⚠ **현재 diff 범위에만 유효** — Q2에서 모듈·저장소 전체를 고르면 Instant 선택 불가(범위 조용한 축소 방지, Codex 2차), low 이상으로 재선택 안내 | **토큰 0** |
| low | 증분·소규모 컴포넌트 한정 | 소 |
| medium | 표준 (일상 권장) | 중 |
| high | 컴포넌트 확대 + gap-fill | 대 |
| max | 전 컴포넌트·검증 패널 전체 | **극대 — 754k+ 토큰 실사용 보고 (세션 통째 소진급)** |

**Q2 범위**: 현재 diff / 특정 모듈(경로 지정) / 저장소 전체 — max×전체 조합은 소모 경고를 선택지 설명에 명시.

## §2 실행·검증 규약

- 결과는 security 에이전트 4관점(S1~S4) 프레임으로 정리해 보고 — 발견의 **차단 자격은 검수 4요건 동일** (플러그인 보고도 액면 수용 금지, 도달 경로 확인 후 채택).
- 패치 자동 생성 기능은 **제안까지만** — 적용은 사용자 승인 후 coder 경유 (검수 게이트 통과).
