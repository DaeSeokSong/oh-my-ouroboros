# 실험 결과 설명 형식 (MANDATORY — 2026-07-15 사용자 정식 채용)

> **로드 시점**: 실험 결과(ablation·factorial·모델/조건 비교 — 프로젝트 무관)를 사용자에게 보고하거나 Confluence 등에 문서화할 때.
> **근거**: 실험 결과 이해에 필요한 4요소 — (a)전체 조망 (b)변화 격리 (c)지표×대상 2축 해석 (d)이상값 대비 현재 위치 — 를 한 흐름에 고정한다. 채용 계기: 2026-07-15 ablation 보고에서 사용자가 "정식 채용, 앞으로 동일 적용" 지시 (형식은 프로젝트 무관 — 어떤 실험이든 비교축과 지표만 치환).

## 형식 (순서 고정)

1. **전체 결과표 먼저** — 전 arm/셀/조건을 한 표에 (열 = 핵심 지표). 판정 배지(★PASS/양성 · 🏆승격 · ❌폐기/음성) 포함.
   - **열별 최고·최저 강조** (평균/집계 행 제외): Confluence 등 html 매체 = 셀 배경색(최고 초록 · 최저 빨강, `data-background`), 마크다운/터미널 = 최고 `**굵게**`+🟢 · 최저 🔴 (색상 불가 매체 폴백).
2. **비교축별 분해** — 각 축(예: 학습 단계·데이터셋/코호트·조건·모델 변형·시드 그룹)마다 소표:
   - **맨 위 "이상값(ideal)" row** — 각 열의 최적값(↑지표=최대 · ↓지표=최소). 정의된 목표치가 없으면 +∞(↑) / −∞(↓)로 표기해 "무한히 좋아질 수 있는 축"임을 드러낸다.
   - 아래에 비교 대상 row들(backbone / 변형 / 조건 등), 괄호 = 직전 항목 대비 Δ.
3. **열(지표)별 해석** — 각 지표가 비교 대상들 사이에서 무엇을 보여주는가 (1지표 1줄~).
4. **행(대상)별 해석** — 각 대상의 프로파일 (강점·약점·특이점).
5. **항목 종합** — 그 비교축의 결론 1~2줄.
6. 전 축 완료 후 **전체 종합** — 변곡점(계단), 컴포넌트 기여 순위, 축 간 불변성(예: backbone 무관 성립 여부) 등 축을 가로지르는 결론.

## 적용 범위

- **모든 프로젝트의 실험 결과** 보고·문서화 (연구 실험뿐 아니라 벤치마크·A/B·성능 비교 일반).
- 단일 결과(비교축 없음) = 1(전체 표)만. 비교축 1개 이상 = 2~6 전부.
- 프로젝트별 실험 로그 문서의 결과 분석 섹션도 이 형식을 따른다.
- 수치 신뢰 기준은 experiment 스킬 준수: 단일 수치 금지 — mean ± std (N ≥ 3) 또는 사용 seed 전체 명시.
